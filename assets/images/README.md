# 圖片命名規則（自動讀取，不用改程式碼）

`assets/images/` 底下有 5 個依用途分類的資料夾。只要把圖片依照下面的規則命名、放進對應資料夾，
遊戲就會自動讀到對的圖，**不需要改任何程式碼**，重新整理網頁就會生效。

所有分類統一使用 **`.png`** 格式。

## `card/` — 角色 / 武器卡片 ICON

檔名：`card_<角色id>.png`

`<角色id>` 對應 `不朽之旅.xlsx` 裡 **card** 分頁的「角色id」欄位。

例：card 分頁新增一列角色id 為 `10032`，把圖存成 `card_10032.png` 放進這個資料夾，遊戲就會自動顯示。
還沒放圖片的卡片會維持空白（不會顯示破圖），之後隨時補圖都會自動生效。

## `skill/` — 技能特效素材

檔名：`skill_<特效名稱>.png`

`<特效名稱>` 對應 **skill** 分頁裡 `prefeb_atk` / `prefeb_hit1` / `prefeb_hit2` 欄位填的文字
（例如 `slash`、`fire`、`heal`、`buff`、`explode`...）。

只要在 skill 分頁填一個新的特效名稱，並把對應的 `skill_<名稱>.png` 放進這個資料夾即可，
不需要是既有的名稱。找不到對應圖片時該次特效不會顯示（不會出現破圖）；遠程攻擊
（`prefeb_atk`）找不到對應圖片時，會自動改用預設的 `skill_throw.png`。

## `text/` — 劇情對話立繪

檔名：`<角色中文名稱>.png`（**不要**加 `text_` 前綴，資料夾本身已經是分類了）

`<角色中文名稱>` 必須跟 text 分頁對話裡「角色名：對話內容」的角色名稱**逐字完全一樣**
（例如 `艾琳`、`魔王`、`永恆聖鏡`）——差一個字、或多打一個空格都會抓不到圖，請直接複製
xlsx 裡冒號前面的文字來當檔名，最保險。

⚠️ 這一類多一個步驟：新增一個要顯示立繪的角色時，除了放圖片，還要到 `index.html` 裡搜尋
`STORY_PORTRAITS`，加一行指定這個角色的立繪要顯示在畫面的左邊/右邊/中間，例如：

```js
'新角色名稱': { side: 'left' },   // side 可以是 'left' / 'right' / 'center'
```

這一步沒辦法從檔名自動判斷（要顯示在哪一側是導演選擇），需要人工指定一次；指定過後，
之後只要換圖片檔案即可，不用再改這一行。

同一個角色如果劇情裡會用不同稱呼講話（例如「魔王」跟「魔王奧斯維德」都可能出現），
兩個名稱都要各自有一張對應的圖（可以是同一張圖存兩份不同檔名），並在 `STORY_PORTRAITS`
各自加一行，這樣不管劇情用哪個稱呼，立繪都抓得到。

## `equipment/` — 裝備 ICON（目前保留，尚未使用）

檔名：`equipment_<裝備id>.png`

`<裝備id>` 對應 **equipment** 分頁的 `id` 欄位。目前所有裝備都還是用預設 emoji 顯示；
上傳對應檔名的圖片後，會自動換成圖片顯示，emoji 會自動隱藏。

## `item/` — 道具 ICON（目前保留，尚未使用）

檔名：`item_<道具id>.png`

`<道具id>` 對應 **item** 分頁的 `id` 欄位。目前所有道具都還是用預設 emoji 顯示；
上傳對應檔名的圖片後，會自動換成圖片顯示，emoji 會自動隱藏。

---

其餘資料夾內沒有分類前綴的圖片（背景、UI 邊框、稀有度徽章、選單圖示等）維持原樣，
不屬於這次整理的範圍，不會受影響。
